1. Executive Summary & The Core Problem

The Origin Story

JanRakshak Vision was born during Tradition Hacks 2026. While AI technology is advancing rapidly, it has birthed a dark side: hyper-realistic deepfakes, AI-generated fraud, and digital manipulation. Currently, 47% of Indian internet users encounter deepfakes, yet there is absolutely no tool available for ordinary, non-technical citizens to verify what they see.

Real-World Problems We Solve

We built this platform to combat documented, real-world crises:

  • Digital Arrest Scams: Scammers are using deepfaked video calls posing as CBI/Police officers. In early 2024, the MHA reported 7,061 victims lost over ₹120.30 crore.
  • Financial & Endorsement Fraud: Viral deepfake videos of Mukesh Ambani, Virat Kohli, and Ratan Tata endorsing fake trading apps have defrauded tens of thousands of users.
  • Local/Cultural Scams (Kolkata Context): Fake Durga Puja donation drives using AI-generated pandal photos, and Bengali celebrity deepfakes promoting fake investment schemes over WhatsApp.

🎯 The Core Pitch

An AI-powered deepfake detector so intuitive that a 65-year-old grandmother can verify a suspicious WhatsApp forward in 3 seconds, entirely in her native language (Hindi/Bengali/English) — without creating an account or paying a single rupee.

2. Project Philosophy & Core Pillars

  1. Accessibility First: No login walls, no paywalls, no complex dashboards. Just a simple drag-and-drop interface.
  2. Multilingual by Default: India operates in vernacular languages. We ship with full native support for English, Hindi (हिन्दी), and Bengali (বাংলা).
  3. Absolute Privacy: We operate a strict "Zero-Storage" policy. We are not building a database of user photos; we are providing a utility.
  4. Actionable Outcomes: We don't just output a probability score. We output plain language: REAL, SUSPICIOUS, or FAKE, alongside direct links to report malicious files to the Cyber Police.

3. End-to-End Technical Architecture

JanRakshak Vision is built on a highly decoupled, scalable, and 100% free tech stack.

Frontend Layer (Client)

  • Framework: React 18 + Vite
  • Styling: Vanilla CSS with CSS Variables (Custom Theme System avoiding Tailwind bloat)
  • State Management: React Hooks (useState, Context API for Themes)
  • i18n: react-i18next for seamless language switching
  • Hosting: Vercel Edge Network (Global CDN)

Backend Layer (API & Inference)

  • Framework: FastAPI (Python 3.10) for high-speed, asynchronous REST endpoints
  • Machine Learning: Hugging Face transformers pipeline
  • Image Processing: Pillow (PIL)
  • Hosting: Hugging Face Spaces (CPU Tier, Dockerized, Free tier)

🔄 The Data Flow

User visits Vercel → Uploads file to Browser RAM → Streams binary via HTTPS POST → FastAPI receives in RAM → Runs Inference → Returns JSON → Backend Memory is instantly flushed.

4. Deep Dive: The "3-Brain" AI Ensemble (v7)

Our biggest technical achievement is moving away from a single-model dependency. Single models have blind spots. We engineered a Weighted Multi-Model Ensemble, running 3 specialized AI "Brains" in parallel:

🧠 Brain 1: The Generative AI Expert (Weight: 35%)

Base: haywoodsloan/ai-image-detector-deploy
Role: Highly trained on latent diffusion outputs. Excels at catching images generated by Midjourney v6, DALL-E 3, SDXL, and Gemini.

🧠 Brain 2: The Texture & Artifact Expert (Weight: 35%)

Base: Organika/sdxl-detector
Role: Analyzes the mathematical noise of an image. Catches artificial skin textures, impossible lighting bounces, and pixel-level anomalies.

🧠 Brain 3: The Composite & Edit Expert (Weight: 30%)

Base: umm-maybe/AI-image-detector
Role: Crucial for detecting traditional manipulation (Photoshop). If a scammer puts a fake face on a real police uniform, this brain catches the mismatched edges.

5. The Smart Heuristic Engine (Algorithmic Logic)

If we merely averaged the scores, edge-cases would break the system. We built a custom Heuristic Engine in Python to apply intelligent logic:

  • 🚀 The High-Confidence Amplifier: If any single model returns a score >85% Fake, the engine calculates a massive multiplier to boost the final score, ensuring the threat is not buried by an average.
  • 🛡️ The Composite Protection Floor: If the Composite Expert (Brain 3) strongly flags an image, the engine mathematically "floors" the final score to a minimum of SUSPICIOUS. Dangerous edits are never marked as safe.
  • 🖼️ The Screenshot Filter: AI models falsely flag UI screenshots as "fake". We pass the image through PIL. We extract the unique color count. If we detect massive uniform flat areas, the engine recognizes it as a UI screenshot and dampens the Fake score by 60%, eliminating false positives.

Output Verdict Thresholds

  • ❌ FAKE (Score >= 50%)
  • ⚠️ SUSPICIOUS (Score >= 30%)
  • ✅ REAL (Score < 30%)

6. Data Privacy & Zero-Storage Policy

In the age of surveillance capitalism, JanRakshak Vision takes a radical stance on privacy: We store nothing.

  • No Databases: There is no SQL/NoSQL database attached to this project.
  • RAM-Only Processing: The FastAPI server receives the image directly into system memory (RAM).
  • Instant Deletion: The moment the inference finishes, the Python Garbage Collector destroys the image data from memory.
  • No Logs or Trackers: We do not log hashes, metadata, or use Google Analytics / Cookies.
